# FH6 Radio Clean v0.2 Windows preview

This is an onedir preview of the independently written v0.2 UI shell. Extract
this directory as a whole and run `FH6-Radio-Clean-v0.2.exe`. Do not delete
`_internal`; it contains the bundled runtime and Qt libraries.

This preview does not include Spotify OAuth, WinRT metadata integration, or a
validated FH6 wire profile. See the repository README and PROVENANCE.md.
